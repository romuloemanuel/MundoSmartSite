# Tema Mundo Smart

Tema filho do Hello Elementor usado em [mundosmartoficial.com.br](https://mundosmartoficial.com.br).

Este repositório tem **só o tema**. Banco, fotos da biblioteca, `wp-config.php` e plugins ficam na Hostinger.

## Atualizar o site (Hostinger)

1. No hPanel: **Avançado → Git**
2. Repositório: `https://github.com/romuloemanuel/MundoSmartSite.git`
3. Branch: `main`
4. Pasta de destino:

`public_html/wp-content/themes/hello-elementor-child`

5. Clique em **Implantar**
6. Limpe o cache (LiteSpeed) e abra o site em aba anônima

Fotos e vídeos dos carrosséis continuam no WordPress: menu **Fotos e vídeos**. Depois de salvar, o cache é limpo.

Não copie para a Hostinger o `wp-config.php` do computador (ele é do ambiente local).
